# AGENTS.md — Rules

## Behavior rules (set by owner)

- **Permission before heavy/medium-duty work:** every time a task is heavy- or medium-duty (memory- and token-intensive), ask first and wait for the answer. Ask as a yes/no question, with a bullet list of exactly what I'm going to do. Only start after "yes".
- **No helpful extras:** do only what was asked. Add extras, fixes, or suggestions beyond the request only when explicitly told to.
