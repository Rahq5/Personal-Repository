# what are the aims?

when i order you to start this flow, you should seek for the TOC.md file and tidy it up 

# operation steps

once you're in the directory where TOC.md file is located you should tidy up the TOC and update it
according to the rest of the same-level files.

# Rules 

- each TOC should have only two levels as maximum.
-  if you didnt find any TOC.md ask first if make a new one and tell me the first 4 files in the same directory and 2 of second levels
- Display aliases on every wikilink — [[File#Heading|Clean Label]], so the TOC shows readable names instead of raw heading slugs
- Title-casing + typo fixes in the display text only (e.g., History of evoultion → "History of Evolution", How AI Companies bills? → "How AI Companies Bill") while leaving the link targets untouched so links don't break
- Normalized heading hierarchy — the old version mixed ####, #####, ###### levels under sections; the tidy-up flattens to ##/###
- Disambiguating labels for overlapping sections — "(Full Notes)", "(Overview)", "(Basics)", "(Deeper Notes)"
- Dropped scratch/personal entries — e.g., the "avg got overrwritten but it kept the value 6.5" debugging lines were removed
- Expanded sections for newer notes (LLM, LLM Inference, the research note) mirroring each note's internal structure
